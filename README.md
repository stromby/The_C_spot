# 🏗️ Do Betão ao Byte: O Estaleiro de Código em C 🚀

Olá! Bem-vindos ao meu repositório central de desenvolvimento em **C**.

Sou um **Engenheiro Civil** em reconversão profissional e este espaço serve como o diário de bordo da minha jornada digital. Aqui guardo todos os projetos oficiais do **Common Core da 42** e as resoluções de algoritmos de plataformas externas.

---

🎯 Estrutura do Repositório

Para manter a organização limpa e sem entulho, o repositório está dividido em duas secções principais:

🏰 1. 42 Common Core
Projetos oficiais desenvolvidos sob as regras estritas da Norminette e com gestão manual de memória.

      📂 libft/ — A minha biblioteca nativa em C, recriando funções essenciais da Libc e expandida com a **Parte Bónus de Listas Ligadas** (Concluído com 125%! 🚀).
    📂 ft_printf/ — Recriação da famosa função de output formatado de C (Concluído! 🎉).
        └── 📂 libft/ — (Integrada!) A minha biblioteca nativa foi totalmente embutida dentro do printf, gerando a biblioteca estática final (libftprintf.a) através de Makefiles modulares.
    📂 get_next_line/ — Função otimizada para ler texto linha a linha a partir de um File Descriptor utilizando variáveis estáticas e gestão rigorosa de memória (Concluído! 🎉).
    📂 push_swap/ — Algoritmo de ordenação de dados numa stack com foco em otimização e complexidade temporal (Concluído! 🎉).

🕹️ 2. Oficina de Jogos (Laboratório de Treino)
Mini-jogos desenvolvidos do zero em C puro para treinar lógica de programação, controlo de buffers (`stdin`), tabelas ASCII e renderização em modo texto adaptada a terminais modernos.

    📂 guess_the_number/ — Jogo de adivinhação blindado contra inputs inválidos e com interface CLI interativa.
	📂 minesweeper/ — O clássico Campo Minado com algoritmo de inundação recursiva (Flood Fill) para propagação de células vazias, controlo de tempo dinâmico e suporte UTF-8 na consola.
    📂 tic_tac_toe/ — O clássico Jogo do Galo renderizado com caracteres UTF-8 Box-Drawing e lógica matricial linearizada.
	📂 wordle/ — O famoso jogo de adivinhação de palavras de 5 letras em modo multilíngue (EN/PT). Integra o meu get_next_line nativo para ler os dicionários e implementa um algoritmo de dupla passagem para gerir o histórico de cores ANSI.

🐝 3. Desafios de Programação (Maratona Digital)
Resoluções de problemas de lógica e matemática organizados por plataforma.

    📂 beecrowd/ — Resolução de problemas estruturados por tipo/nível (ex: 1 - Beginner / 1000 - Hello World!).
    📂 outras-plataformas/ — Desafios ocasionais do LeetCode ou HackerRank.
